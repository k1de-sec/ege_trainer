# ЕГЭ+ — изменения версии 1.3

- Реально разделены основные разделы: `index.html`, `topics.html`, `self-study.html`, `theory.html`, `official.html` содержат разные наборы блоков.
- Удалены скрытые копии чужих разделов из каждой HTML-страницы.
- Навигация открывает соответствующие HTML-документы, а не якоря на длинной главной.
- `app.js` безопасно работает на страницах, где отсутствуют элементы тренажёра; интерактивный банк доступен только на страницах тем и самоподготовки.
- Сохранённый пробный вариант восстанавливается на странице самоподготовки, а открытие информационных страниц не перезаписывает незавершённую сессию.
- Кэш service worker обновлён до `ege-trainer-web-v10`; offline fallback больше не выдаёт главную вместо другой страницы.
- Содержимое банка заданий и ссылки на ФИПИ в этом исправлении не изменялись.
