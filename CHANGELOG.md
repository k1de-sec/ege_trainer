# ЕГЭ+ — журнал изменений

## v1.6 — мультипредметная архитектура

- Добавлен каталог 15 предметов ЕГЭ с отдельными базовым и профильным направлениями математики.
- Добавлена отдельная страница-паспорт каждого выбранного предмета и subject-aware URLs для тем, самостоятельной работы, теории и официальных источников.
- Добавлен единый реестр `subjects.json` с тематическими направлениями, прозрачным статусом наполнения и прямыми ссылками на официальные материалы ФИПИ за 2027 (проекты) и 2026 годы.
- На страницах предметов без готового банка больше не показывается математический банк; вместо него показываются карты направлений, статус и официальные источники.
- Контекст выбранного предмета сохраняется при переходах; прогресс тренажёра подготовлен к раздельному хранению по предметам.
- Добавлены тесты каталога, маршрутизации, JSON и service-worker shell.
- Визуальный стиль ЕГЭ+ сохранён и расширен карточками предметов.


## v1.7
- Увеличена типографика основного текста, навигации, подписей и элементов каталога.
- Ограничена ширина строк в описаниях для более комфортного чтения.

## v1.8 — стабилизация и очистка

- Унифицирован радиус карточек основных учебных сценариев без изменения их содержимого и поведения.
- Сохранена закреплённая шапка и повышена устойчивость её слоя при прокрутке.
- Добавлена поддержка системной настройки уменьшения анимации.
- Обновлён service-worker cache до `ege-trainer-web-v13-cleanup`, чтобы клиенты получили свежие стили и скрипты.
- Удалён устаревший ZIP-архив из корня сайта: архивы не должны попадать в публичную сборку GitHub Pages.
- Добавлен `.gitignore` для локальных архивов, кэшей Python и файлов операционной системы.
