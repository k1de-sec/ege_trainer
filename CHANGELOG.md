# ЕГЭ+ — журнал изменений

## v1.8.3 — полный учебный блок информатики

- Добавлена учебная карта всех 27 позиций ЕГЭ-2027: цель задания, алгоритм решения, мини-пример с объяснением и типичные ошибки.
- Добавлены поиск по конспекту и фильтры по частям экзамена.
- Добавлены ссылки на актуальные материалы ФИПИ-2027, Полякова, «Решу ЕГЭ» и КЕГЭ; авторский конспект не копирует их задания.
- Запуск Python перенесён в отдельный Web Worker с лимитом времени, ограничением вывода и понятными сообщениями об ошибках.
- Проверка кода теперь запускает программу на контрольном входе задания, а не просто сравнивает случайный последний вывод.
- Добавлены проверки полноты 27-раздельного конспекта, наличия тестов для программных заданий и кеширования новых файлов.


## v1.8.2 — устойчивость каталога и поиск

- Исправлена ошибка в проверке данных: тест учитывает актуальные 28 авторских упражнений профильной математики.
- Если каталог не загрузился, главная и страницы предметов показывают понятное сообщение и кнопку повторной загрузки.
- Исправлен поиск по нескольким словам; добавлены быстрые клавиши `Ctrl/⌘ + K` и `/`, а также состояние для экранных дикторов.
- Уточнена подпись банка профильной математики: авторские упражнения, не официальные задания ФИПИ.
- Обновлён кэш service worker, чтобы браузер забирал исправленную версию скриптов.


## v1.6 — мультипредметная архитектура

- Добавлен каталог 15 предметов ЕГЭ с отдельными базовым и профильным направлениями математики.
- Добавлена отдельная страница-паспорт каждого выбранного предмета и subject-aware URLs для тем, самостоятельной работы, теории и официальных источников.
- Добавлен единый реестр `subjects.json` с тематическими направлениями, прозрачным статусом наполнения и прямыми ссылками на официальные материалы ФИПИ за 2027 (проекты) и 2026 годы.
- На страницах предметов без готового банка больше не показывается математический банк; вместо него показываются карты направлений, статус и официальные источники.
- Контекст выбранного предмета сохраняется при переходах; прогресс тренажёра подготовлен к раздельному хранению по предметам.
- Добавлены тесты каталога, маршрутизации, JSON и service-worker shell.
- Визуальный стиль ЕГЭ+ сохранён и расширен карточками предметов.


## v1.7
- Увеличена типографика основного текста, навигации, подписей и элементов каталога.
- Ограничена ширина строк в описаниях для более комфортного чтения.

## v1.8 — стабилизация и очистка

- Унифицирован радиус карточек основных учебных сценариев без изменения их содержимого и поведения.
- Сохранена закреплённая шапка и повышена устойчивость её слоя при прокрутке.
- Добавлена поддержка системной настройки уменьшения анимации.
- Обновлён service-worker cache до `ege-trainer-web-v13-cleanup`, чтобы клиенты получили свежие стили и скрипты.
- Удалён устаревший ZIP-архив из корня сайта: архивы не должны попадать в публичную сборку GitHub Pages.
- Добавлен `.gitignore` для локальных архивов, кэшей Python и файлов операционной системы.

## v1.8.1 — реальные варианты ФИПИ

- Добавлены прямые ссылки на официальные открытые варианты КИМ ЕГЭ-2026 для всех 15 предметов каталога.
- В разделе официальных материалов добавлена отдельная карточка для оригинального варианта выбранного предмета.
- В режиме самоподготовки добавлен прямой переход к оригинальному варианту 2026 года, если для предмета нет собственного интерактивного банка.
- Сохранены ссылки на общий открытый банк ФИПИ и на страницу со всеми вариантами.
- Обновлён service-worker cache до `ege-trainer-web-v14-official-variants`.
- В автоматические проверки добавлена проверка официального архива для каждого предмета и ссылки на карточку варианта.
- Важно: архивы открываются у ФИПИ; полная интерактивная копия всех вопросов в локальном тренажёре ещё не создана.
