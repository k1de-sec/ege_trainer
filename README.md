# Тренажёр ЕГЭ — сайт для GitHub Pages

Это статический сайт: HTML, CSS, JavaScript и JSON. Сборка, Node.js и GitHub Actions для публикации не нужны.

## Загрузка в GitHub через браузер

1. Распакуйте архив в отдельную папку.
2. Откройте свой репозиторий на GitHub.
3. Нажмите **Add file → Upload files**.
4. Перетащите все файлы из распакованной папки в окно браузера. Важно: `index.html` должен оказаться в корне репозитория, а не внутри дополнительной папки.
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Deploy from a branch**, затем ветку `main` и папку `/(root)`, нажмите **Save**.
7. После публикации адрес появится в Settings → Pages.

Если репозиторий уже содержит `README.md`, можно загрузить только файлы сайта, не заменяя README.

Сайт доступен всем пользователям после публикации. Не загружайте в репозиторий пароли, токены и личные данные.

## Состав

- `index.html` — страница тренажёра.
- `styles.css` — адаптивная вёрстка.
- `app.js` — логика интерфейса и проверки ответов.
- `tasks_data.json` — авторские тренировочные задания базовой математики.
- `manifest.webmanifest`, `sw.js`, `favicon.svg` — дополнительные возможности веб-приложения.

Задания авторские, это не официальный вариант ФИПИ. Прогресс пока хранится только в браузере; аккаунтов и облачной синхронизации нет.
