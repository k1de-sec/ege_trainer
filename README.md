# ЕГЭ+ — мультипредметная платформа подготовки к ЕГЭ (v1.6)

Статический сайт для GitHub Pages. Основные разделы — самостоятельные HTML-документы. Текущий этап переводит проект от сайта только по базовой математике к платформе для 15 предметов ЕГЭ.

## Страницы

- `index.html` — главная страница платформы и быстрый выбор предмета.
- `subjects.html` — каталог всех 15 учебных предметов ЕГЭ. Математика показана с отдельным выбором базового и профильного уровней.
- `subject.html?subject=...` — паспорт выбранного предмета, его основные направления, статус банка и переходы к разделам.
- `topics.html?subject=...` — темы и варианты выбранного предмета.
- `self-study.html?subject=...` — самостоятельная работа по выбранному предмету.
- `theory.html?subject=...` — тематическая карта для теории.
- `official.html?subject=...` — официальные материалы соответствующего предмета.

Разделы тем, подготовки, теории и источников — отдельные HTML-страницы, а не скрытые секции одной длинной страницы. Выбор предмета хранится в параметре URL и в `localStorage`, поэтому переходы сохраняют контекст.

## Предметы и честный статус наполнения

`subjects.json` — единый каталог 15 предметов, тематика для планирования обучения и прямые ссылки на источники. В него входят русский язык, математика, физика, химия, информатика, биология, история, обществознание, география, литература и пять иностранных языков: английский, немецкий, французский, испанский и китайский. Математика включает два направления: базовый и профильный уровни.

- **Математика, базовый уровень:** доступен локальный банк из 441 авторского упражнения — по 21 варианту на каждый из 21 номеров, отдельные форматы ответа и пробник на 180 минут. Это авторские задания, а не официальные задания ФИПИ.
- **Математика, профильный уровень:** в данных есть два демонстрационных шаблона, но полноценный банк и пробник ещё не готовы. Интерфейс не выдаёт их за полный тренажёр.
- **Остальные 13 предметов:** доступны самостоятельные страницы, карта направлений и прямые ссылки на оригинальные источники. Собственные банки вопросов, теория и автоматическая проверка будут добавляться отдельно после содержательной проверки. Пока эти разделы не помечены как полноценные тренажёры.

## Официальные материалы

ФИПИ публикует демоверсии, спецификации и кодификаторы для каждого предмета: https://fipi.ru/ege/demoversii-specifikacii-kodifikatory . В каталоге предметов и на страницах предметов есть ссылки на открытый банк ЕГЭ, открытые варианты, пакет документов 2027 года и утверждённые материалы 2026 года. На текущей официальной странице ФИПИ документы ЕГЭ-2027 обозначены как **проекты**, поэтому они так же подписаны в интерфейсе. Перед подготовкой и публикацией заданий следует сверять статус материалов на сайте ФИПИ.

Открытый банк: https://ege.fipi.ru/bank/ . Открытые варианты: https://fipi.ru/ege/otkrytyy-bank-zadaniy-ege/otkrytyye-varianty-kim-ege . Оригинальные условия и рисунки остаются на стороне официального источника; мы не переписываем их и не подменяем своими задачами.

## Техническая структура

- `multi-exam.js` — выбор предмета, каталог карточек, маршрутизация контекста и страницы для предметов без локального банка.
- `subjects.json` — реестр предметов, направления, статусы наполнения и официальные URLs.
- `app.js` — работающий тренажёр базовой математики, включая краткие и составные ответы, выражения, изображения, интерактивные графики, прогресс и экзаменационный режим.
- `tasks_data.json` — исходный локальный банк упражнений.
- `fipi_links.json` — ссылки на официальные примеры математики.
- `styles.css` — общий фирменный стиль и компоненты мультипредметной навигации.
- `sw.js` — service worker, включающий новые страницы и файлы в cache shell.

Прогресс основного тренажёра записывается в локальный браузер и имеет ключ, привязанный к выбранному предмету. Облачные аккаунты и синхронизация устройств в эту версию не входят.

## Проверки

Запускать из корня папки сайта:

```bash
node --check app.js
node --check multi-exam.js
for f in scripts/test_*.py; do python "$f"; done
node scripts/test_advanced_answers.js
node scripts/test_solution_renderer.js
```

Для разработки используйте локальный HTTP-сервер, а не `file://`, чтобы `fetch()` мог загружать JSON:

```bash
python -m http.server 8000
```

## Публикация GitHub Pages

1. Распакуйте архив.
2. В репозитории `k1de-sec/ege_trainer` нажмите **Add file → Upload files**.
3. Загрузите содержимое папки версии 1.6 в корень репозитория, заменив старые файлы. Не загружайте сам ZIP вместо содержимого.
4. Проверьте, что среди файлов присутствуют `subjects.html`, `subject.html`, `subjects.json`, `multi-exam.js`, обновлённый `sw.js`, все пять текущих HTML-страниц, `app.js`, `styles.css`, `tasks_data.json` и `fipi_links.json`.
5. Нажмите **Commit changes**; настройку Pages менять не нужно, если текущая публикация уже работает из корня ветки.
6. Откройте сайт и выполните `Ctrl+F5`. При наличии старого service worker проверьте прямые адреса: `/subjects.html`, `/subject.html?subject=russian`, `/topics.html?subject=physics`, `/theory.html?subject=chemistry`.

## Граница текущей версии

Эта версия — архитектурная подготовка платформы для множества ЕГЭ: каталог, предметные маршруты и официальные источники уже подключены, но полные собственные банки не создаются автоматически из источников. Перед тем как включить конкретный предмет в режим пробного экзамена, нужно добавить проверенные задания, ответы/критерии, разборы, изображения и структуру оценивания именно этого предмета.
