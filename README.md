# ЕГЭ+ — тренажёр базовой математики (веб-версия 1.1)

Статический сайт для GitHub Pages: HTML, CSS, JavaScript и JSON; сервер для базы авторских задач не нужен.

## Что изменилось в 1.1

- Исправлена обработка старых переносов строк вида `\n\n` в условиях и разборах: они превращаются в настоящие абзацы, не затрагивая команды вроде `\neq`.
- Знаки умножения `\cdot` и `\times` отображаются как читабельные `·` и `×` с интервалом; добавлен регрессионный тест рендерера.
- Исправлены требования UI-теста: они сверяются с фактическим ID отдельного блока «Самоподготовка».

## Что было изменено в 1.0

- Навигация разделена на самостоятельные разделы: главная, темы и варианты, самоподготовка, теория и официальные материалы.
- Темы и варианты сгруппированы в четыре подгруппы. Внутри каждой доступны номера заданий и количество тренировочных вариантов. Кнопка открывает все задачи выбранного номера.
- Самоподготовка — отдельный блок: короткая разминка из 5 случайных задач, смешанная подборка из 21 типа и авторский пробный вариант на 180 минут.
- Добавлены краткие теоретические конспекты с формулами и кнопками перехода к соответствующим заданиям.
- Исправлено отображение математических выражений в условиях и разборах: `\cdot` отображается как `·`, корни, степени, дроби и `\operatorname{НОК}` преобразуются в читаемую форму без внешнего рендерера.
- Сохранены поиск, ответ/проверка, разбор, типичные ошибки, localStorage-прогресс и таймер экзамена.
- Весь банк включает 441 авторскую тренировочную задачу — 21 задача по каждому из 21 номеров базовой математики. Эти задачи не являются официальными КИМ ФИПИ.
- В блоке ФИПИ остаются ссылки на официальный открытый банк, навигаторы и открытые варианты. Сайт не скачивает и не копирует автоматически содержимое официального банка.
- Service Worker обновлён для очистки старого кеша после публикации.

## Разделы сайта

1. **Главная** — коротко о тренажёре и локальном прогрессе.
2. **Темы и варианты** — четыре подгруппы тем, выбор номера и список вариантов слева в банке.
3. **Самоподготовка** — 5 случайных задач, 21 смешанная задача без таймера или пробный вариант на 180 минут.
4. **Теория** — краткие памятки по числам и алгебре, практическим задачам, графикам/вероятности и геометрии.
5. **ФИПИ** — официальные материалы и отдельные ссылки на источники.

## Публикация в GitHub Pages

1. Скачай ZIP и распакуй.
2. Зайди в репозиторий `k1de-sec/ege_trainer` → `Add file` → `Upload files`.
3. Загрузи содержимое папки обновления в корень репозитория, заменяя одноимённые файлы.
4. Нажми `Commit changes`.
5. Открой сайт и нажми `Ctrl+F5`. Service Worker cache version is bumped to v7 to refresh cached assets.

## Проверки

- `node --check app.js` — синтаксис JavaScript.
- `python scripts/test_site.py` — структура данных и обязательные элементы интерфейса.
- `python scripts/test_site_ui.py` — уникальность ID и связность интерфейса.
- `node scripts/test_solution_renderer.js` — математические символы, абзацы и списки в разборах.

Все локальные задачи являются авторскими тренировочными материалами. Требования к экзамену сверяй с актуальными документами ФИПИ.
