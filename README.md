# ЕГЭ+ — тренажёр базовой математики (веб-версия 0.9)

Статический сайт для GitHub Pages: HTML, CSS, JavaScript и JSON. Для собственной базы не нужен сервер.

## Что нового в 0.9

- 441 авторская тренировочная задача по базовой математике: 21 вариация для каждого из 21 номеров. Задачи размечены по теме, имеют краткий ответ и разбор. Это авторские вариации, а не дословная копия ФИПИ.
- Пробный вариант из 21 задания, таймер на 180 минут, автосохранение ответов, переходы между номерами, итоговый подсчёт и список задач на повторение.
- Случайная подборка из собственной базы — выбирается по одному случайному варианту на каждый номер.
- Новая кнопка «Случайное задание ФИПИ»: открывает случайный официальный пример по ID из навигаторов самостоятельной подготовки ФИПИ 2026. В режиме отдельного задания кнопка «Пример ФИПИ №…» открывает один из доступных примеров того же номера.
- Если в навигаторе ФИПИ для данного номера нет списка прямых идентификаторов, открывается общий официальный банк заданий.
- Добавлены ссылки на официальный открытый банк, документы и открытые варианты ФИПИ, а также на рекомендованные в навигаторе учебные материалы.
- Прогресс и ответы остаются в localStorage этого браузера.
- Форматы тренировок разведены по отдельным карточкам: отработка одного типа, смешанная подборка без таймера и авторский пробный вариант на 180 минут.
- На главной странице добавлен короткий блок «Почему ЕГЭ+» с преимуществами и честным разделением авторских задач и ссылок на ФИПИ.

## Что означает «динамическая подборка ФИПИ» в этой версии

Сейчас динамически выбирается официальный вопрос по случайному ID из списка примеров, который ФИПИ публикует в навигаторах самостоятельной подготовки. Ссылка открывает вопрос на `ege.fipi.ru`; текст вопроса не загружается и не копируется в наш сайт. Это устойчивее для статического GitHub Pages, чем пытаться читать содержимое внешнего сайта в браузере: отдельного стабильного открытого API для такого сценария здесь не используется.

Полная автоматическая синхронизация содержимого банка не реализована. Для неё нужен отдельный серверный процесс, проверка доступности банка, условий использования и обработка изменений его страниц. Кнопка с ID даёт динамический выбор реального официального примера, но не означает, что локальная база автоматически обновляется из ФИПИ.

## Загрузить обновление на GitHub Pages

1. Скачай ZIP и распакуй его.
2. Открой репозиторий `ege_trainer` → `Add file` → `Upload files`.
3. Загрузите содержимое архива в корень репозитория и подтверди замену файлов. Не загружай сам ZIP в качестве единственного файла.
4. Нажми `Commit changes`. Не нужно менять настройки Pages, если сайт уже опубликован.
5. Открой сайт и сделай жёсткое обновление `Ctrl+F5`. Для Service Worker увеличена версия кеша, поэтому новая база должна подтянуться после обновления.

## Перегенерация вариантов локально

`python scripts/generate_variants.py` пересоздаёт локальные авторские варианты: 20 добавочных вариантов для каждого номера к исходному варианту.

## Проверки

`python scripts/test_site_data.py` проверяет уникальность ID задач, количество заданий по типам, наличие ответов/разборов и целостность списка ссылок ФИПИ. `python scripts/test_site_ui.py` проверяет HTML-ID и соответствие JS-привязок элементам страницы. Синтаксис JavaScript можно проверить командой `node --check app.js`.
