# ЕГЭ+ — сайт-тренажёр (версия 1.3)

Статический сайт для GitHub Pages. Каждая вкладка — самостоятельный HTML-документ с собственным содержимым; страницы не содержат спрятанные копии остальных разделов.

## Разделы

- `index.html` — только главная, преимущества и переходы в разделы.
- `topics.html` — каталог типов заданий, ссылки на оригинальные примеры ФИПИ и авторские упражнения по выбранной теме.
- `self-study.html` — только блок самостоятельной работы и тренажёр для разминки, смешанной подборки и пробного варианта с таймером.
- `theory.html` — только краткая теория, сгруппированная по направлениям.
- `official.html` — только официальные ресурсы: банк ФИПИ, открытые КИМ, навигаторы и ссылки на примеры. В `topics.html` эти прямые ссылки также стоят в начале раздела, до авторских упражнений.

## Важная точность о содержимом

`tasks_data.json` содержит 441 авторское тренировочное упражнение, в том числе сгенерированные варианты по общим типам задач. Встроенные формулировки не являются оригинальными текстами ФИПИ. Они **не являются дословными заданиями ФИПИ или «СДАМ ГИА»** и в интерфейсе всегда помечаются как авторские.

Оригинальные задания в разделе источников не перепечатываются и не переформулируются: ссылки открывают конкретный пример в официальном банке ФИПИ. Так исходная формулировка, числа, рисунки и контекст остаются у первоисточника. В каталоге ФИПИ есть открытый банк и опубликованные открытые варианты КИМ: https://fipi.ru/ege/otkrytyy-bank-zadaniy-ege .

Сайт `СДАМ ГИА` используется как пример логики навигации. Их материалы не копируются на сторонний сайт: собственные правила портала прямо ограничивают размещение их материалов на других ресурсах. Ссылка ведёт на первоисточник: https://ege.sdamgia.ru/ .

Если в будущем будет получено разрешение на воспроизведение точного банка заданий или подходящий открытый набор данных с понятными условиями использования, нужно будет импортировать формулировки **дословно**, включая изображения, таблицы, ответы, год и ссылку на источник, без изменения чисел и контекста. До этого официальный контент открывается у источника, а авторский банк остаётся отдельным.

## Возможности

- 441 авторское тренировочное упражнение в отдельном учебном банке. Числа 1–21 используются для навигации внутри банка и не означают, что текст является оригинальным заданием ФИПИ.
- В начале раздела «Темы и варианты» — прямые переходы к исходным примерам ФИПИ-2026 и ссылка на полный открытый вариант КИМ.
- Каталог тем сгруппирован в четыре направления.
- Отработка одного типа заданий, разминка, смешанная подборка и пробный вариант на 180 минут.
- Прогресс и ответы сохраняются в локальном хранилище браузера.
- Ссылки на официальные примеры ФИПИ открывают первоисточник в новой вкладке.

## Публикация GitHub Pages

1. Распаковать архив.
2. В репозитории `k1de-sec/ege_trainer` открыть **Add file → Upload files**.
3. Перетащить содержимое папки версии 1.3 в корень репозитория, включая все пять HTML-страниц.
4. Убедиться, что загружены все пять HTML-файлов, `app.js`, `styles.css`, `tasks_data.json`, `fipi_links.json` и обновлённый `sw.js`, затем нажать **Commit changes**.
5. Открыть `https://k1de-sec.github.io/ege_trainer/` и выполнить `Ctrl+F5`.

В этой версии страницы действительно разные по HTML: главная не содержит теорию, страницы тем и самоподготовки не содержат контент теории/источников, а страница источников не содержит каталог упражнений. Это не CSS-переключение разделов внутри одной страницы.

Настройка Pages через Actions не нужна, если текущая публикация уже работает из ветки и корня репозитория. После обновления открывай страницы по отдельным адресам `.../topics.html`, `.../self-study.html`, `.../theory.html` и `.../official.html`. Служебный cache version повышен, чтобы браузер загрузил новые HTML-документы.
